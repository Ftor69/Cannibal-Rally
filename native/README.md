# Экспериментальные исходники мода The Forest / ModAPI

**Source-only, in-game unverified. Это не готовый выпуск Melty.** Для проверки используйте одиночную desktop-игру без VR и других модов. Сделайте резервную копию сохранений. Веб-ZIP из `releases/` для этих действий не подходит.

## Локальная сборка на Windows

1. Нужна установленная копия **The Forest** (Steam App 242760), Visual Studio с C# build tools и targeting pack, который запросит ваш generated project. ModAPI: [официальный сайт](https://modapi.survivetheforest.net/) и [официальный репозиторий](https://github.com/FluffyFishGames/ModAPI). Выберите версию, которая распознаёт именно вашу игру. Не устанавливайте одновременно несколько загрузчиков. Эти инструменты в облачной среде не установлены: сетевой прокси недоступен, Windows/игра отсутствуют.
2. В ModAPI выберите The Forest, задайте каталог с `TheForest.exe`, на Development создайте проект с ID **CannibalRallyExperimental**. Имя/описание явно пометьте experimental; совместимость и framework должны быть созданы ModAPI по вашей установленной игре, а не введены наугад.
3. Из checkout этого PR запустите (Python 3):

   ```powershell
   python scripts/prepare_modapi.py 'C:/ModAPI/projects/TheForest/CannibalRallyExperimental/CannibalRallyExperimental.csproj'
   ```

   Скрипт копирует только `native/Core` и `native/Runtime`, добавляет Compile entries, сохраняет реальные refs/framework и резервную копию `.csproj.pre-rally.bak`. Можно добавить те же шесть C#-файлов через Visual Studio вручную. `ModInfo.xml` остаётся сгенерированным ModAPI.
4. Откройте generated `.sln` в Visual Studio, соберите Release. При неизвестном типе/члене не заменяйте DLL заглушкой: проверьте refs и установленную версию через ILSpy. Это обязательная первая проверка наших игровых API. Директория выходного файла определяется generated project.
5. В ModAPI выберите проект и **Create Mod**. Полученный `.mod` находится в `mods/TheForest/`; включите только его и запускайте через **Start Game**. Не копируйте DLL в случайный каталог `Mods/` и не переименовывайте ZIP в `.mod`.
6. Загрузите одиночный мир, встаньте на открытом ровном участке. Нажмите F6. Если нативный rig/API несовместим, код остановится с ошибкой в Unity player log; это не подтверждённая версия мода.

## Управление кандидата

| Действие | Клавиша |
|---|---|
| Создать/восстановить машину один раз в текущем мире | F6 |
| Посадка / выход после остановки | F7 |
| Газ, задний ход, руль | WASD |
| Тормоз | Space |
| Собрать оригинальный ящик в пределах 3 м пешком | F5 |
| Сохранить машину, стоя вне неё | F8 |
| Ремонт: одна деталь → +25 прочности | F9 |
| Перелить резервное топливо в бак | F10 |

Ремонт и заправка работают пешком в пределах 4 м от остановившейся машины. При выходе код ищет свободное место сбоку/сзади. Если скорость выше 0.5 м/с или места нет, выход отклоняется. Двенадцать ящиков с оригинальными ресурсами размещаются вокруг исходной точки: чётные дают 5 л, нечётные одну деталь. На участках без безопасной поверхности ящик не создаётся; это ограниченный набор, не loot из native inventory.

## Сохранения и конфигурация

Первый F6 создаёт `CannibalRally/config.xml` в `Application.persistentDataPath`. Найдите путь через Unity/игровой log или системный каталог данных The Forest. Для вашей сборки точный Windows-путь нужно подтвердить в игре; скрипт его не угадывает. Пример настроек — `native/config.example.xml`.

`Profile` выбирайте отдельно для каждого мира/слота, например `solo-slot1`. Разрешены латинские буквы, цифры, `_` и `-`. Изменяйте конфигурацию вне игры, до F6. Сохранение: `<Profile>.xml`, предыдущее — `.xml.bak`. F8 сохраняет положение, угол, топливо, прочность, резерв, детали, исходную точку ящиков и реестр собранных. The Forest сохраняйте отдельно штатным способом. Автосохранения нет.

Повреждённый/неизвестный XML не перезаписывается автоматически: мод останавливается. После закрытия игры можно восстановить `.bak` копированием или выбрать новый профиль; сначала сохраните проблемный файл. При невозможности загрузить машину на безопасной поверхности код не телепортирует её в другую точку молча.

## Проверки перед любым выпуском

Проверьте весь сценарий из [VALIDATION.md](../docs/VALIDATION.md), особенно native player pivot, камеру, столкновения и смерть при посадке. `native/Tests/CoreTests.csproj` использует **те же Core-файлы**, но не игровые DLL. Успех такого теста не подтверждает Unity-сборку.

В Melty пока не устанавливайте ничего: сначала нужен ответ `game_info` о loader/install support, корректно созданный `.mod`, проверенный рецепт и успешные `inspect_package`, `validate_recipe`, `one_click_check`, реальный запуск и screenshot именно этого мода. Лицензия/remix также не установлены. Подробности — [HANDOFF.md](../docs/HANDOFF.md).
