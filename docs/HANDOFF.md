# Передача v0.1 через GitHub

Это автономный веб-прототип. ZIP не является подтверждённым форматом Melty или готовым модом The Forest. Публикация в Melty не выполнялась. Для адаптации нужны официальная спецификация импорта / SDK, точная поддерживаемая версия игры и локальная проверка интеграции; см. COMPATIBILITY.md.

## Состав поставки

- Исходники, интерфейс и ресурсы процедурной модели: `src/`, `index.html`.
- Зависимости и зафиксированные версии: `package.json`, `package-lock.json`.
- Автоматические проверки: `tests/`, `scripts/browser-check.mjs`.
- Документация: `README.md`, `docs/`.
- Проверенный ZIP и SHA-256: `releases/`.

В ZIP: одна папка `cannibal-rally/`, исходники, тесты, документация и `dist/`. ZIP не содержит сам себя, `.git`, `node_modules`, `work`, секретные настройки или закрытые инструкции Melty. SHA-256 подтверждает целостность архива, но не совместимость с платформой.

## Проверки перед отправкой

`python scripts/package.py` создаёт ZIP из явно разрешённых файлов и проверяет каждое содержимое до упаковки и после распаковки. Проверяются безопасные пути, отсутствие дубликатов, CRC, соответствие байтов и ссылки на ассеты. Для воспроизводимости фиксируются даты и права файлов в ZIP.

Шаблоны проверки секретов включают GitHub/OpenAI/AWS/Slack токены, приватные ключи, литеральные пароли и credential-параметры, URL с логином и паролем. Дополнительно проверяются staged-файлы и хосты зависимостей lockfile. Никакие значения потенциальных секретов не печатаются. Эти проверки не заменяют ручной обзор новых файлов и специализированный аудит.

Для новых изменений выполните `npm test`, `npm run build`, `python scripts/package.py` и проверьте `git diff --cached` перед коммитом. Секреты не храните даже в игнорируемых файлах, если их предполагается загружать в GitHub. Готовый архив предназначен для скачивания и отдельного запуска в браузере.
