# Что необходимо для выпуска через Melty

Цель и режим уже определены: оригинальное внедорожное survival-вождение **в The Forest**, solo, без обязательных гонок. Forza — вдохновение, не dependency. Не нужно повторно выяснять игровые механики или запрашивать Publish prompt: он предоставлен в разговоре. Нельзя сохранять его токен в git.

Черновик: `ac0b8860-c43e-4624-a98d-063ad1cb068e`. По предоставленным инструкциям первым вызовом должен быть `mod_status`, затем `list_my_mods`, `search_games` и `game_info`. Сейчас MCP-соединение невозможно: исходящий HTTP-прокси на порту 8080 не доступен; melty.gg также не включён в разрешённые направления среды. Это не ошибка авторизации и не свидетельство отсутствия поддержки The Forest.

## Конкретные условия продолжения

1. Рабочее сетевое подключение среды к `https://melty.gg/api/mcp` через разрешённую конфигурацию. Использовать существующий токен только в Authorization header к Melty, получить реальные schemas через `tools/list`, проверить JSON-RPC errors и `result.isError`.
2. По `game_info` установить, умеет ли Melty устанавливать нужный ModAPI и `.mod`. Если нет, даже проверенный ModAPI-мод ещё не соответствует цели one-click: нужен поддерживаемый и лицензированно распространяемый installation/launch путь. Не придумывать рецепт, game ID или loader name.
3. Windows и установленная The Forest/ModAPI с предоставленными самой игрой refs. Собрать generated project; устранить фактические API incompatibilities; получить `.mod` через Create Mod.
4. Запуск, проверки из VALIDATION, screenshot текущей native версии. Старые web screenshots не подходят. Готовность AI/physics/rig не подтверждается core tests.
5. Установить права распространения и remix: LICENSE в исходном проекте нет. Не объявлять MIT или remix-разрешение за владельца.
6. Проверить архив и рецепт через `inspect_package`, `validate_recipe`, `one_click_check` с честным feature list. Если требуется ручная установка или сопутствующий запуск, сначала исправить; не загружать исходники/веб-сборку как first playable release.
7. Только после успешных проверок создать ZIP с actual size/hash, загрузить, submit release, загрузить реальный screenshot. Не публиковать незавершённую сборку. Не выполнять эти операции лишь для получения красивого статуса.

`melty.json` сохраняется только после получения и валидации реального recipe; сейчас такого файла нет. Не выполнены upload/submit/publish и серверная проверка статуса. Listing пока не редактировался: недоступен MCP, отсутствует playable verified build.

Предлагаемое название после проверки: **Cannibal Rally — The Forest Off-road Survival**. Слоган: «Исследуйте остров на багги, ищите топливо и поддерживайте машину на ходу». Описание должно включать только прошедшие in-game проверки функции; не обещать Forza, multiplayer или готовый vehicle-targeting AI.
