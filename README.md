# CANNIBAL RALLY — v0.1

Автономный одиночный 3D-прототип выживания и внедорожного вождения, вдохновлённый The Forest и Forza Horizon 5. **Интеграция с Melty / The Forest не подтверждена и не реализована.** Никаких вызовов предполагаемых API, загрузки чужих ресурсов, публикации или отправки секретов.

## Запуск на компьютере

Нужны Node.js 22.12+ (либо 20.19+) и браузер с WebGL 2. Проверено на Node 24.19.0.

```sh
git clone https://github.com/Ftor69/Cannibal-Rally.git
cd Cannibal-Rally
# Если PR ещё не слит, переключитесь на его ветку:
# git switch cannibal-rally-v0.1
npm ci
npm run dev
```

Откройте http://localhost:5173. Интернет нужен при установке зависимостей, игра после сборки не обращается к внешним сервисам.

```sh
npm test
npm run build
npm run preview
```

Готовая сборка находится в `dist/`. Открывайте её через HTTP, не через `file://`. Для проверки уже собранной версии без Node: `python -m http.server 8080 --directory dist`, затем http://localhost:8080.

Браузерный тест: запустите `npm run dev` в отдельном терминале, затем `npm run test:browser`. По умолчанию тест использует `/usr/bin/chromium`; на Windows/macOS задайте `CHROMIUM_PATH` как путь к установленному Chrome/Chromium. Скриншот пишется в `work/prototype.png`.

## Управление

- WASD: движение пешком; газ / задний ход / руль в автомобиле.
- Space: тормоз. E: посадка в пределах 4 м; выход только после остановки.
- F: ремонт; G: топливо. Обслуживание только в круге лагеря, при остановке.
- H: еда; R: начать или перезапустить необязательный маршрут из 6 точек без дедлайна.
- Enter: перезапуск всей игры, прогресс сбрасывается.

Старт рядом с багги. Лагерь отмечен кругом. Каннибалы и мутанты преследуют игрока и наносят урон с интервалом; в автомобиле повреждается его прочность. При голоде теряется здоровье. Гонка вознаграждает запчастями, канистрой и едой. При попадании багги в воду он возвращается к старту с потерей прочности.

## Реализовано

Оригинальный оранжевый багги с чёрным каркасом, сиденьями, фарами, металлическими дисками и крупными шинами с протектором. Материалы PBR, тени, вид от третьего лица. Четыре raycast-колеса cannon-es, пружины и демпферы, тяга на всех колёсах, поворот передних колёс, торможение, физические столкновения с деревьями, камнями и рампой. Игровая логика отделена от рендера.

## Структура

- `src/core.js`: ресурсы, здоровье, взаимодействия, враги, гонка; не зависит от браузера.
- `src/physics.js`: cannon-es мир, полный привод, подвеска и коллайдеры.
- `src/buggy.js`: оригинальная процедурная 3D-модель.
- `src/main.js`: остров, интерфейс, ввод, камера, фиксированный шаг 60 Гц.
- `tests/core.test.js`: 8 проверок правил и реальной физики.
- `scripts/browser-check.mjs`: сквозной браузерный тест.
- `docs/COMPATIBILITY.md`: результаты проверки совместимости.
- `docs/VALIDATION.md`: результаты и локальный чек-лист.

## Ограничения первой версии

Это тестовый самостоятельный движок в браузере, а не загружаемый мод Melty. Модель багги детальнее примитива, но **не фотореалистичный готовый ассет**. Остров преимущественно плоский; рампа проверяет работу подвески. Враги — упрощённые капсулы с преследованием без обхода препятствий, боевых анимаций и полноценной системы боя. Нет сохранений, аудио, строительства, инвентарного UI, цикла дня/ночи, контроллера и сенсорного управления. Камера сглажена, но не предотвращает прохождение через деревья. Полный привод и подвеска физические, но это не автомобильная симуляция уровня Forza.

Для продолжения интеграции нужны официальная документация Melty, локальный SDK, точная версия The Forest и подтверждённый способ запуска модов. См. `docs/COMPATIBILITY.md`.

## Передача через GitHub и ZIP

Исходники и документация находятся в этом репозитории. Подготовка для GitHub означает сохранение и проверку веб-прототипа; возможность импорта в Melty **не подтверждена**. Для совместимости нужны официальный SDK/контракт импорта, поддерживаемая версия The Forest и локальная проверка загрузчика (подробнее в [COMPATIBILITY.md](docs/COMPATIBILITY.md)). Не загружайте архив как готовый игровой мод.

Проверенный архив: `releases/cannibal-rally-v0.1.zip`, контрольная сумма: `releases/cannibal-rally-v0.1.zip.sha256`. В GitHub откройте ZIP и нажмите **Download raw file**. Если изменения пока в PR, выберите ветку `cannibal-rally-v0.1`. Архив содержит одну корневую папку `cannibal-rally/`, все исходники, документацию, lockfile и собранный `dist/`; зависимости, Git-метаданные и локальные настройки исключены.

После распаковки выполните команды запуска из папки `cannibal-rally`. Для пересборки архива требуется Python 3:

```sh
npm run build
python scripts/package.py
```

Скрипт проверяет содержимое на распространённые шаблоны секретов, безопасные пути ZIP, CRC, соответствие файлов исходникам и наличие ассетов сборки. Проверка шаблонов не гарантирует обнаружение любого возможного секрета; перед отправкой новых файлов проверяйте их содержимое. Не сохраняйте токены, пароли и закрытые инструкции Melty в репозитории. GitHub Actions и автоматическая публикация Melty в проекте не настроены.
