# Cannibal Rally — native The Forest work in progress

Цель проекта — одиночный внедорожный survival-мод **для The Forest**, вдохновлённый вождением Forza. Forza Horizon 5 не требуется: её код и ресурсы не используются.

**Готового мода для запуска через Melty пока нет.** В `native/` добавлены оригинальные C#-исходники для документированного загрузчика ModAPI. Они не собраны против игровых DLL и не проверены в игре. Формат установки ModAPI через Melty не подтверждён ответом `game_info` / проверкой рецепта. ZIP для Melty, фиктивный `melty.json` и публикация не создавались.

## Что добавлено

- Оранжево-чёрный процедурный багги: Rigidbody, четыре WheelCollider, подвеска, полный привод, тормоза, снижение тяги при повреждении, фары.
- Посадка настоящего игрока, камера от третьего лица, выход после остановки с проверкой свободного места; восстановление изменённых компонентов при выходе и завершении.
- Расход топлива, отдельный запас канистр, ремонт деталями. Двенадцать оригинальных ящиков возле исходной точки машины; повторный сбор блокируется сохранённым реестром.
- Столкновения с коллайдерами реального игрового мира и урон от ударов. Native AI, здоровье и остальной мир остаются игровыми.
- Ручные XML-сохранения состояния машины и собранных ресурсов с резервной копией; отдельный профиль, не связанный автоматически со слотом сохранения The Forest.
- Свободное исследование без гонок и ограничения времени. Мультиплеер отключён при работающей Bolt-сессии.

Это описание написанного кода, **не подтверждение работоспособности в игре**. Урон, полученный сидящим игроком, также повреждает багги; источник урона не различается. Отдельная атака каннибалов по машине и полноценная интеграция с инвентарём The Forest не реализованы. Не обещается физика уровня Forza.

## Сборка и запуск

Следуйте [native/README.md](native/README.md): используйте проект, сгенерированный вашим ModAPI из установленной игры, добавьте исходники скриптом подготовки, соберите и создайте `.mod` через ModAPI. Нельзя устанавливать C#-исходники или старый веб-ZIP как игровой мод.

```sh
python scripts/check_native.py
python -m unittest discover -s native/Tests -p 'test_*.py' -v
# .NET 8 SDK: только тест общей логики, не сборка Unity-мода
dotnet run --project native/Tests/CoreTests.csproj --configuration Release
```

## Старый браузерный прототип

`src/`, `index.html`, npm-скрипты и `releases/cannibal-rally-v0.1.zip` — прежний автономный веб-прототип. Он не запускается внутри The Forest и не является пакетом Melty. Его код сохранён для истории; развитие браузерной игры в этой работе не выполнялось. Прежняя инструкция: [LEGACY_WEB.md](docs/LEGACY_WEB.md).

## Права и публикация

Новые модели создаются из примитивов Unity, игровой контент и DLL не включены. В исходном репозитории не было LICENSE: общая лицензия и разрешение на remix не установлены и не выдуманы. Перед публичной дистрибуцией необходимо установить эти условия и проверить зависимости. Токен Melty и инструкции с токеном не сохраняются в репозиторий.
